# متحكم المنبه (Android)

تطبيق أندرويد أصلي يضبط منبهات حقيقية (AlarmManager.setAlarmClock)
تعمل والشاشة مقفلة: توقظ الشاشة، ترن بصوت المنبه، وتهتز.

## طريقة الحصول على APK بدون Android Studio (من الهاتف أو الكمبيوتر)
1. أنشئ مستودعاً جديداً على github.com وارفع كل محتويات هذا المجلد (بما فيها .github).
2. افتح تبويب Actions ثم Build APK ثم Run workflow (أو يعمل تلقائياً عند الرفع).
3. بعد انتهاء البناء افتح التشغيلة ونزّل الملف alarm-apk (داخله app-debug.apk).
4. ثبّته على الهاتف (اسمح بالتثبيت من مصادر غير معروفة).

## طريقة Android Studio
File > Open > اختر هذا المجلد > انتظر المزامنة > Build > Build APK(s).

## إعدادات مهمة بعد التثبيت
- السماح بالإشعارات.
- السماح بالإشعارات بملء الشاشة (أندرويد 14: سيفتح التطبيق الإعداد تلقائياً).
- الإعدادات > التطبيقات > متحكم المنبه > البطارية > غير مقيّد (Unrestricted).
